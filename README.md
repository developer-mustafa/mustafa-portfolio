# Mustafa Rahman — Portfolio

A responsive bilingual portfolio for Mustafa Rahman, Full Stack Software Engineer, Founder & Director at MR IT Software Solution Ltd, and ICT Lecturer.

## Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- English / Bangla language toggle

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. The portfolio includes About, Skills, Experience, Focus areas, Education, and Contact sections. Experience dates and education details are kept aligned with the supplied resume facts. Focus cards describe areas of work, not client case studies.
